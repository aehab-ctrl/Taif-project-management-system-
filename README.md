# نظام إدارة المشاريع | جامعة الطائف
### Taif University — Project Management System

نظام إدارة مشاريع احترافي، يعمل بالكامل من طرف المتصفح (Client-side)، بدون الحاجة لخادم أو قاعدة بيانات — جاهز للنشر مباشرة على **GitHub Pages**.

## المحتويات

```
├── index.html                                  ← التطبيق الكامل (افتحه مباشرة أو انشره)
├── templates/
│   ├── Progress-Update-Template.xlsx           ← نموذج تقرير أداء مشروع فارغ (Excel)
│   ├── Project-Schedule-Template.xlsx          ← نموذج جدول زمني فارغ (Excel)
│   └── Cost-Management-Plan-Template.docx      ← نموذج خطة إدارة تكاليف فارغ (Word)
└── README.md
```

## المزايا

- **محفظة جاهزة بـ 65 مشروعاً فعلياً** مستوردة من الخطة التنفيذية لعمادة التعليم الإلكتروني وتقنية المعلومات (2026–2028)، بأهدافها ومبادراتها الاستراتيجية ومؤشرات أدائها، وبتقديرات مالية واقعية (ميزانية، صرف فعلي، صرف مخطط) لكل مشروع محسوبة بناءً على مدته وطبيعته (بنية تحتية/أمن سيبراني أعلى تكلفة، تدريب/خطط أقل تكلفة)، بإجمالي محفظة يقارب 68.6 مليون ريال سعودي.
- **لوحة تحكم تنفيذية** لمحفظة المشاريع (الحالة، الميزانية، نسبة الإنجاز).
- **إدارة كاملة للمشاريع**: إضافة/تعديل/حذف، الربط الاستراتيجي (المبادرة/الأهداف/المؤشرات)، مؤشرات إنجاز (Milestones)، مهام وجدول زمني (Gantt).
- **توليد تقارير حالة تنفيذية احترافية** لكل مشروع بصيغة "لوحة تنفيذية" من 3 صفحات (ملخص تنفيذي مع مؤشرات ورسوم بيانية، جدول زمني ربعي للمعالم الرئيسية، جدول مخرجات) — بكل الحقول معبأة دائماً دون ترك أي خانة فارغة. **يُنزَّل التقرير كملف Word (`.doc`) قابل للتعديل مباشرة** (وليس PDF)، مع خيار الطباعة المباشرة كبديل ثانوي.
- **تعبئة آلية للنماذج الرسمية بصيغة Word/Excel**: اختر أي مشروع من المحفظة ونزّل أياً من 7 نماذج معبأة تلقائياً ببياناته — ميثاق المشروع، شهادة إنجاز/صرف دفعة، إغلاق المشروع، طلب تغيير (Word)، بالإضافة إلى تقرير تحديث التقدم والجدول الزمني للمشروع (Excel)، وخطة إدارة تكاليف المشروع (Word) — دون ترك أي حقل فارغ. كما تبقى النماذج الرسمية الأصلية الكاملة (بأوراقها ولوحاتها ومخططات جانت الأسبوعية) متاحة للتنزيل فارغة بصيغتها الرسمية الكاملة لمن يحتاج التعبئة اليدوية الشاملة. جميع النماذج بهوية جامعة الطائف الكاملة.
- **نماذج فارغة جاهزة للتنزيل** (Excel/Word) بنفس نماذج مكتب إدارة المشاريع، ويمكن ربطها تلقائياً باسم أي مشروع وتاريخ اليوم.
- **تصدير Excel/CSV** لمحفظة المشاريع، وتصدير/استيراد نسخة احتياطية كاملة (JSON).
- **تخزين محلي بالكامل** عبر `localStorage` — لا حاجة لخادم أو حساب.
- هوية بصرية متوافقة مع هوية جامعة الطائف (الذهبي `#D5B254` والأخضر `#537E54`).

## النشر على GitHub Pages

1. أنشئ مستودعاً (Repository) جديداً على GitHub وارفع محتويات هذا المجلد كما هي (حافظ على مجلد `templates/`).
2. من إعدادات المستودع: **Settings → Pages**.
3. تحت **Source** اختر الفرع (Branch) `main` والمجلد `/root`، ثم اضغط **Save**.
4. بعد دقيقة أو دقيقتين سيصبح النظام متاحاً على الرابط:
   `https://<username>.github.io/<repo-name>/`

لا حاجة لأي إعداد إضافي (Build step)، فالملف `index.html` يعمل مباشرة كصفحة ثابتة.

## ملاحظات هامة

- **البيانات محلية للمتصفح**: كل مستخدم يرى فقط البيانات التي أدخلها على جهازه ومتصفحه. لمشاركة البيانات بين عدة أجهزة، استخدم زر "تصدير نسخة احتياطية" من صفحة الإعدادات ثم "استيراد" على الجهاز الآخر.
- لتغيير الشعار: استبدل الصورة المُضمّنة (Base64) داخل `index.html` في المتغير `LOGO_B64`، أو عدّل السطر الخاص بـ `logoImg.src`.
- لتغيير اسم النظام أو الجهة: صفحة **الإعدادات** داخل النظام.
- الملفات داخل `templates/` هي نفس نماذج مكتب إدارة المشاريع الأصلية بصيغتها القابلة للتعديل، ويمكن استبدالها بنسخة محدثة من فريقكم دون أي تعديل على الكود، بشرط الإبقاء على نفس أسماء الملفات.
- **نماذج "التعبئة الآلية"** (ميثاق المشروع، شهادة إنجاز، إغلاق مشروع، طلب تغيير، خطة إدارة التكاليف، تقرير تحديث التقدم، الجدول الزمني، وتقرير حالة المشروع) تُبنى بالكامل داخل المتصفح ولا تحتاج لملفات خارجية. جميع الحقول تُملأ دائماً — إما من بيانات المشروع الفعلية أو بافتراض معقول محسوب تلقائياً (مثل توزيع معالم زمنية قياسية إذا لم تُسجَّل معالم فعلية) — بحيث لا تظهر خانات فارغة في المستند الناتج. الاستثناء الوحيد هو حقول التوقيع وأسماء الأشخاص الفعليين وبيانات التواصل الشخصية، التي تبقى فارغة لتعبئتها يدوياً لأنها تتطلب توثيقاً حقيقياً لا يمكن افتراضه. الملفات المكتبية (ميثاق/شهادة/إغلاق/تغيير/خطة تكاليف) تُصدَّر بصيغة Word (`.doc`)، وملفات الجداول (تحديث التقدم/الجدول الزمني) تُصدَّر بصيغة Excel (`.xls`) — كلها متوافقة تماماً مع Microsoft Office.
- **الفرق بين "النماذج المعبأة تلقائياً" و"النماذج الأصلية الفارغة"**: القسم الأول ينشئ نسخة مبسطة وجاهزة القراءة مباشرة من بيانات النظام. القسم الثاني (أسفل صفحة النماذج) يوفر الملفات الرسمية الأصلية بكامل تنسيقها وأوراقها المتعددة كما وردت من مكتب إدارة المشاريع، فارغة تماماً، لمن يحتاج التنسيق الرسمي الكامل للتعبئة اليدوية.

## التقنيات المستخدمة

HTML5 و CSS3 و JavaScript خام (Vanilla JS) بدون أي إطار عمل (Framework) أو خطوة بناء (Build step)، ما يجعل النظام خفيفاً وسريع التحميل وسهل الصيانة والنشر.
